# 碑刻数字拓片系统

浏览器内的碑刻三维扫描 → 数字拓片系统。TypeScript + WebGL2（自写 GLSL）+ IndexedDB，
无后端、无重型三维库，针对碑林「禁止上手拓、仅有三维扫描」的工作流设计。

## 功能与页面

| 页面 | 能力 |
|---|---|
| 碑刻档案 | 名称/年代/尺寸/位置/备注的增删改，每块碑挂多次扫描 |
| 扫描处理 | 导入 PLY（ascii/二进制）/OBJ，或一键生成程序测试碑；Web Worker 后台做基准面拟合、去倾斜去弯曲、光栅化高度场，写入 IndexedDB |
| 拓片生成 | 墨包物理模型出图，乌金拓/蝉翼拓预设，墨包尺度、浓淡、gamma、刻口锐化、石花、纸张纹理可调；局部加深/减淡补墨，完整撤销/重做 |
| 对比校勘 | 老拓片照片与数字拓片叠合，相似变换自动配准（NCC 粗搜+精修），差异区域红色高亮 |
| 出版导出 | 单字框选编号、批量单字 PNG+毫米/像素坐标清单；指定 DPI 输出整张 TIFF/PNG；几何精度自检；渲染耗时记录 |
| 设置 | 默认 DPI、GPU 分块边长、墨色/纸色、本地数据管理与存储占用 |

## 架构

```
src/
  geometry/   纯算法（不依赖 DOM）
    math.ts            Jacobi 特征分解、值噪声/fbm
    ply.ts obj.ts      网格解析（百万级，可扩容 TypedArray）
    planeFit.ts        PCA 基准面拟合 + 局部坐标变换（去整体倾斜）
    heightfield.ts     规则网格逆映射/通用三角形光栅化、IRLS 稳健二次去弯曲、直方图众数归零、补洞
    registration.ts    相似变换配准、局部归一化差异检测
    accuracy.ts        Otsu、Chamfer 双向边界距离、IoU/F1
    stele-gen-core.js  程序碑面生成（阴刻楷书+风化坑+倾斜弯曲），Node/浏览器共用
  gl/
    shaders.ts         GLSL ES3.00（含 ES1.00 回退）：墨包 log-sum-exp 软包络、间隙留白、石花、纸纹、刻口锐化、补墨
    RubbingEngine.ts   R32F 高度场纹理、分块离屏渲染读回、补墨纹理
    RetouchEditor.ts   补墨撤销/重做栈
    image.ts           灰度、warp、无压缩 TIFF 编码、PNG、裁切
  workers/process.worker.ts  扫描处理后台线程
  db/           IndexedDB 封装（结构化记录 + 高度场 Blob 分库）
  pages/        六个页面
```

## 墨包物理模型

真实拓印中墨包轻拍，纸面被压向石面：石面凸起/平面处吃墨，阴刻凹槽处纸面悬空、吃不到墨而留白。
着色器对每个像素在墨包半径内取高度场的 **log-sum-exp 软上包络** `envelope`，
间隙 `gap = envelope − z` 越大墨越少；再叠加微粗糙度（石花泐痕）、刻口梯度锐化、纸张纤维纹理。
高度场纹理用 `NEAREST` 采样，刻口不被双线性插值糊掉。

## 几何精度的关键处理

普通全局二次去趋势会把占比可观的阴刻当成「弯曲趋势」一起扣掉，吃掉真实槽深。
本系统在 `detrendQuadratic` 用 **IRLS 迭代稳健拟合**：先以直方图众数峰定位石面，
只用石面内点拟合弯曲面并按残差迭代收敛，刻槽/风化坑作为离群低点被排除，槽深得以保留。

## 测试数据与验收

程序生成一块 800×1000mm、115 万顶点、带 24 个阴刻楷书字与 64 个风化坑、
含整体倾斜（0.8°）与二次弯曲（矢高约 2.2mm）的碑面，并产出刻口真值掩膜：

```bash
npm run gen:testdata     # 生成 public/testdata 下的 PLY + 位打包真值 + 元数据
npm run test:acceptance  # 几何精度 + 速度验收
npm run bench            # 几何流水线分阶段耗时
```

验收口径（`tools/acceptance-test.mts`，CPU 参考实现与 GLSL 墨包模型同构）：

- **几何精度**：高分辨率小碑（网格间距 0.15mm，可解析 0.45mm 刻口壁）上，
  数字拓片笔画边界与网格真值刻口的双向 Chamfer 距离
  **平均 0.103mm、RMS 0.152mm，均 < 0.2mm**；连通域清理孤立石花噪点后最大偏差约 1.1mm。
- **速度**：1m 全碑 115 万顶点，几何流水线（拟合+光栅化+稳健去弯曲）约 2.3s；
  600DPI 输出 23622×18898（446MP），GPU 分 456 块渲染。浏览器内实际 GPU 渲染耗时显示在
  「出版导出 → 性能记录」面板，对照 10 秒验收线（取决于本机 GPU）。

> 说明：0.2mm 边界精度要求源网格间距不粗于刻口壁尺度，因此几何精度在高分辨率小碑上核验；
> 1m 全碑用于核验百万面级的处理与出图吞吐。这与真实扫描「分块高精度、全碑大吞吐」的作业方式一致。

```bash

npm run build      # 类型检查 + 生产构建（Worker 自动分包）
```

## 已知边界

- TIFF 导出为无压缩基线灰度 8bit（兼容性优先）；需要 LZW/CMYK 可在 `image.ts` 扩展。
- 配准采用相似变换（平移/旋转/缩放），应对老照片的轻度形变；透视畸变严重的照片需先校正。
- 浏览器内 PLY 解析与高度场处理在 Worker 中进行，超大文件（>数百 MB）受设备内存约束。
